Project Overview

This application demonstrates the deployment of a machine-learning model developed to estimate one's probability of having either diabetes or borderline diabetes status using demographic, socioeconomic, behavioral, and physical characteristics. The result indicates one's probability at that point in time rather than the probability of developing diabetes over their lifetime.

This model was developed using data from the National Health and Nutrition Examination Survey (NHANES). Multiple machine- learning approaches were evaluated before Gradient Boosting was selected as the final model.

Model Inputs

The model uses the following characteristics:

  • Age
  • Sex
  • Race / ethnicity
  • Income relative to poverty line
  • Body mass index
  • Smoking history
  • Heavy alcohol use
  • Weekly exercise frequency
  • Daily sedentary time

The Flask application converts user-friendly inputs such as height, weight, household income, and household size into the model features required for prediction.

Final Model

The final model is a fine-tuned Gradient Boosting Classifier. Hyperparameters were selected using a grid search and cross-validation with the training data.

Hyperparameter Selected Value
Number of Estimators 250
Learning Rate 0.06
Maximum Tree Depth 1
Minimum Samples per Leaf 2
Subsample 0.8

Final Test Performance

Metric Score
ROC AUC 0.780
Log Loss 0.371
Brier Score 0.115

The final model showed moderate discriminatory ability and reasonably strong probability calibration on the held-out test set. The predicted probability was within 2 percentage points of the observed probability for 97.4% of observations.

Deployment

The preprocessing steps required for inference and the fitted Gradient Boosting model were combined into a scikit-learn pipeline and serialized using Joblib.

Flask loads this pipeline and converts the information submitted through the estimator into a pandas DataFrame. The pipeline then preprocesses the values and generates the estimated probability of diabetes.

Important Limitation

This application is a data-science portfolio project and is not a medical device or validated clinical prediction tool. Predictions should not be used to diagnose diabetes or make healthcare decisions.
